## About

**stagewise** is an open-source agentic IDE for developers with a coding agent built right in.

| Feature | Description |
| :--- | :--- |
| 🖥️ Browse & Build | Work in the same tool — no context switching |
| 🤖 Coding Agent | Full access to your tab's console and debugger |
| 🔬 Temporary or Permanent Edits | Make test changes or connect a codebase for persistent edits |
| 🎨 Reverse Engineering | Extract components, style systems, and color palettes from any website |
| 🔌 IDE Integration | View and apply code changes in your favorite editor |
| 🔑 Bring Your Own Key | Fully supported for all AI providers |

## Model Access

Bring your own API key for all popular model providers. You can also register completely custom providers (including local inference) and define custom models.
